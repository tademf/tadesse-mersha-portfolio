# Tadesse Mersha - Portfolio

A premium dark-theme personal portfolio website.

## Setup
1. Clone the repository.
2. Install dependencies: `npm install`
3. Run the development server: `npm run dev`

## Deployment
1. Build the project: `npm run build`
2. Deploy the `dist` folder to your preferred hosting provider.

## Configuration
- Update component files in `/src/components/` to add real project links, social links, and bio information.
- Place your CV file at `/public/cv/tadesse-mersha-cv.pdf`.
- Configure the contact form in `/src/components/Contact.tsx`.
